### 🛠️ What I build (applied AI in banking)

- **Retrieval & agents** — RAG pipelines and multi-agent Claude Code–style harnesses for internal workflows.
- **Local LLM infra** — self-hosted **vLLM / Ollama** serving on-prem GPU, so nothing leaves the building.
